# ADR 0005: 投放期間才套用接收端轉向鎖定

狀態：接受。

後續修訂：面板入口改由 [ADR 0006](0006-projection-control-entry.md) 定義，不再以返回鍵開啟；以下轉向鎖定決定不變。

使用者可在投放前選擇是否鎖定接收端方向，也可在投放中透過返回鍵面板改變。偏好會保留供下次投放使用，但鎖定效果只存在於投放期間；未投放時 App 仍跟隨系統。啟用鎖定時固定當下的橫向或直向，但允許同一方向內由感測器轉動 180 度；鎖定後可主動切換橫向與直向。解除鎖定即恢復跟隨裝置。未曾明確選擇時預設不鎖定，避免部分 Miracast 來源在旋轉鎖定下表現不佳。這不控制 Windows 來源畫面的方向。
