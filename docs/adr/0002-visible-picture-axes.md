# ADR 0002: 偏好尺寸跟着看見的畫面

狀態：接受。

## 背景

`wm size` 報的是螢幕的基準尺寸，不是使用者當下看見的方向。這台 Fold 5 內螢幕的基準是直向 `1812×2176`；轉成橫向後，使用者看見的是 `2176×1812`。

曾決定「使用此螢幕」與第一次佈建原樣寫入這組基準數字、不對調軸。實測裡 Windows 因此選了直向模式，橫向面板上的畫面被拉變形。詞彙裡的畫面以使用者看見的邊為軸。

## 決定

「使用此螢幕」和那一次佈建，寫入的寬高跟着當下看見的畫面。寬是看見的橫邊，高是看見的豎邊。

內螢幕橫向時得到 `2176×1812`，直向時得到 `1812×2176`。不把 `wm size` 的基準軸原樣保存。

## 後果

- 已存成基準軸的偏好尺寸，不會因為這條決定自己改寫。
- 畫面轉向之後，已保存的偏好尺寸留着。只有再按「使用此螢幕」，或尚未用掉的那一次佈建，才依當下看見的畫面重寫。
