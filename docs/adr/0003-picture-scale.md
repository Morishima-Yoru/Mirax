# ADR 0003: 四種縮放，預設等比

狀態：接受。

## 背景

畫面在面板上的擺法曾收成只有等比：整個看得見、比例不變、不多餘的部分不屬於畫面。實測裡直向的串流被拉進橫向面板，和這條不一致。使用者也要常見的其他擺法，而不是只留一種。

## 決定

縮放有四種，使用者可選，並記住：等比、鋪滿、拉伸、原寸。預設等比。

縮放只描述畫面在面板上的擺法。它不改廣告給 Windows 的模式集合，也不改 Windows 送來的比例。

## 後果

- 連線中途改縮放，立刻作用在目前的畫面。
- 等比置中。鋪滿中心對齊，四周多出來的部分不顯示。原寸左上對齊；畫面大於面板時，右方和下方在面板之外。
